# Switch OID Catalog

Центральный журнал найденных и проверенных OID для коммутаторов Nateks/NetXpert.

## Правила

- Записываем только OID, которые реально проверялись.
- Статус `CONFIRMED` означает, что OID успешно опрошен на указанной модели.
- `SEMANTIC` означает, что значение и назначение OID подтверждены, а не только факт ответа.
- Не переносим OID между моделями без отдельной проверки.
- Для каждого OID указываем модель, индекс, пример результата и где он был найден.
- Если OID оказался нерабочим, сохраняем его со статусом `FAILED`, чтобы не повторять эксперимент.

## NXI-3050: подтверждённый LLDP через Web UI

SNMP OID пока не найден, но наличие LLDP на устройстве подтверждено через Web UI `/ShowLldpPage`.

Пример:
- Local Port ID: `Port_1/2`
- Remote Port ID: `Port_9`
- Remote Management Address: `10.0.110.18`
- Remote System Name: `sw-3030-kp-0km`
- Remote System Description: `NetXpertNXI-3030`

Это подтверждает наличие данных LLDP, но не является подтверждением SNMP OID.

## Как дополнять каталог

При нахождении нового OID добавлять строку с:
1. моделью;
2. полным OID без сокращений;
3. назначением;
4. статусом;
5. командой проверки;
6. фактическим результатом;
7. датой проверки;
8. источником/файлом, если OID взят из документации, MIB или кода.
