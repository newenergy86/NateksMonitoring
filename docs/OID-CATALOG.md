# Switch OID Catalog

Центральный журнал найденных и проверенных OID для коммутаторов Nateks/NetXpert. Ведётся автоматически в процессе работы проекта.

## Правила
- Пользователь не переносит записи сюда вручную.
- Записываем реально проверенные OID, включая нерабочие.
- `CONFIRMED` означает, что OID успешно опрошен на указанной модели.
- `SEMANTIC` означает, что не только ответ, но и назначение OID подтверждены.
- Не переносим OID между моделями без отдельной проверки.
- Для каждого OID по возможности указываем полный OID, индекс, команду проверки и фактический результат.
- `FAILED` сохраняем, чтобы не повторять уже исключённый вариант без новой причины.

## NXI-3050 — LLDP через Web UI

Наличие LLDP на устройстве подтверждено через Web UI `/ShowLldpPage`, но это не подтверждает наличие соответствующего SNMP OID.

Пример:
- Local Port ID: `Port_1/2`
- Remote Port ID: `Port_9`
- Remote Management Address: `10.0.110.18`
- Remote System Name: `sw-3030-kp-0km`
- Remote System Description: `NetXpertNXI-3030`
