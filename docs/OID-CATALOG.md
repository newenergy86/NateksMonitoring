# Switch OID Catalog

Центральный журнал найденных и проверенных OID для коммутаторов Nateks/NetXpert. Ведётся автоматически в процессе работы проекта. Пользователь не переносит записи вручную.

## Статусы
- `CONFIRMED` — OID успешно опрошен на указанной модели.
- `SEMANTIC` — ответ и назначение OID подтверждены.
- `PARTIAL` — ответ подтверждён, но назначение/структура ещё требуют сопоставления.
- `FAILED` — проверка завершилась Timeout/No Such Object или другим отрицательным результатом.
- `UNKNOWN` — найден в источнике, но ещё не проверен на устройстве.

## NXI-3050 — LLDP через Web UI

LLDP на устройстве подтверждён через Web UI `/ShowLldpPage`. Это **не подтверждает наличие соответствующего SNMP OID**.

Зафиксированный пример:
- Local Port ID: `Port_1/2`
- Remote Port ID: `Port_9`
- Remote Chassis ID: `00:0f:d9:04:de:b8`
- Remote Management Address: `10.0.110.18`
- Remote System Name: `sw-3030-kp-0km`
- Remote System Description: `NetXpertNXI-3030`

Также в сохранённом `lldp.html` есть другие соседи, например `Port_1/1 → 10.0.110.22` и `Port_7/2 → 10.0.110.240`.

## Правила дальнейшего поиска

1. Не считать OID рабочим только потому, что он есть в YAML/MIB или работает на другой модели.
2. Для NXI-3050 сначала искать реальную LLDP-таблицу узкими SNMP-запросами.
3. Не повторять перечисленные `FAILED` проверки без новой технической причины.
4. Каждый новый подтверждённый OID сразу добавлять в этот каталог.
