## Следующее действие
Сделать узкие проверки vendor subtree вместо полного `snmpwalk 1.3.6.1.4.1.4249`, который завершается тайм-аутом на длинном выводе. Не предполагать, что таблица интерфейсов `.1.4...` содержит LLDP.

## Правила работы
1. Перед каждым изменением назвать точный объект, поле и ожидаемый результат.
2. За раз — одно изменение.
3. Не менять `app.js` до завершения настройки Zabbix.
4. Не удалять и не заменять существующие LLD правила без доказанной необходимости.
5. После каждой проверки добавлять результат в `docs/HISTORY.md`.
6. Перед импортом YAML сохранять экспорт текущего шаблона из Zabbix.
